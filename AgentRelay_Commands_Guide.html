AgentRelay — CLI & Systems Command Reference

Complete developer reference covering installation, scope management, daemons, MCP agent interop, team collaboration, sudo / zsh permission workarounds, and full lifecycle management.

Target OS: macOS (zsh) / Linux
Version: 1.0.0 (Polaris PRD v0.1)
Authors: Utkarsh Sahoo & Daksh Vaswani
Store: SQLite + FTS5 (~/.agentrelay)
Local Model: Ollama (qwen2.5-coder:7b)
Cloud: LCP Express REST Server (/api/v1)

1. Installation & Global Setup (Including Sudo & Zsh Workarounds)

Method / ScenarioCommand & Functionality
Standard Dependencies npm install --prefix cli
npm install --prefix backend
npm install --prefix frontend
Installs all third-party dependencies across the workspace.
Standard Global Link cd ~/Desktop/DESKTOP/AgentRelay/cli && npm link && cd ..
Symlinks the binary into system PATH (run inside project directory).
Global Install via Path npm install -g ~/Desktop/DESKTOP/AgentRelay/cli
Directly installs the CLI globally from any working directory.
SUDO EACCES Fix A sudo npm install -g ~/Desktop/DESKTOP/AgentRelay/cli
Overcomes macOS permission locks on /usr/local/lib/node_modules. Prompts for Mac password once.
RECOMMENDED EACCES Fix B (Zsh) echo 'alias agentrelay="node ~/Desktop/DESKTOP/AgentRelay/cli/bin/agentrelay.js"' >> ~/.zshrc && source ~/.zshrc
Zero sudo or root permissions needed. Permanent shell alias available in every terminal.
EACCES Fix C (Chown) sudo chown -R utkarshsahoo /usr/local/lib/node_modules /usr/local/bin
Restores write ownership to your user account so global npm commands never require sudo again.
Verification agentrelay --version  (Outputs: 1.0.0)
agentrelay --help  (Displays master command index)

2. Initialization & Opt-In Scope Management

CommandFunctionality
agentrelay initInitializes ~/.agentrelay/, creates SQLite store with WAL mode & FTS5 search index, tests local Ollama runtime, and pulls team context if authenticated.
agentrelay statusShows background watcher state, registered scopes, indexed sessions, scrubbed events count, queue depth, and model status.
agentrelay scope add <path>Registers a directory for session capture. (Strict opt-in: unscoped directories are never opened).
agentrelay scope listLists all folders currently observed for session capture.
agentrelay scope remove <path>Immediately halts session capture for a specific folder.
agentrelay pauseTemporarily pauses all transcript capture across all scopes (zero capture mode).
agentrelay resumeResumes transcript observation across all registered scopes.

4. Review, Feedback, Search & Record Sharing

CommandFunctionality
agentrelay reviewInteractive review: accept, edit (new version), or reject candidate records.
agentrelay review --acceptBatch-accepts all unreviewed candidate records into the verified store.
agentrelay review --rejectBatch-rejects candidate records, removing them from search and promotion.
agentrelay search [query]High-speed offline search over sessions, decisions, and files using SQLite FTS5.
agentrelay search [query] --jsonOutputs matching records in structured JSON schema.
agentrelay show <recordId>Displays formatted record summary, decisions citing evidence IDs, and files touched.
agentrelay show <recordId> --jsonOutputs full record JSON including provenance and sensitivity metadata.
agentrelay share <recordId>Marks record as shareable with your team (private by default).
agentrelay unshare <recordId>Reverts record back to private status.

5. Global Context Sync, Markdown Packs & MCP Server

CommandFunctionality
agentrelay syncMaster Synchronization: Pulls team records, aggregates touched code files, writes markdown packs to ~/.agentrelay/context/record_*.md, and generates CONTEXT.md.
agentrelay export <recordId>Exports a single record as a self-contained Markdown pack (context_pack_*.md).
agentrelay export <recordId> --packIncludes the full raw scrubbed session chat and tool event slice in the Markdown pack.
agentrelay mcpModel Context Protocol Server: Stdio JSON-RPC server with search_context and show_record tools for Claude Code, Cursor, and Zed.

6. Team Collaboration, Handoffs & LCP Cloud

CommandFunctionality
agentrelay loginGitHub OAuth device flow login. Stores token in ~/.agentrelay/auth.json (0o600).
agentrelay login --token <tok>Direct API token authentication.
agentrelay logoutClears local credentials.
agentrelay team create <name>Creates a new isolated team workspace (sets creator as admin).
agentrelay team listLists all team memberships and roles.
agentrelay team inviteGenerates an expiring single-use invite token.
agentrelay team join <token>Joins team using invite token.
agentrelay promote <recordId>Promotes record to team server. Server re-scrubs on ingest and appends to SHA-256 audit chain.
agentrelay unpromote <recordId>Withdraws record and creates tombstone that propagates on pull.
agentrelay pullIncremental pull of team records and tombstones using monotonic sequence cursor.
agentrelay handoff <recId> <@user>Assigns a record directly to a teammate with notification provenance.
agentrelay inboxViews and manages received handoffs (--state pending|read, --read <id>).
